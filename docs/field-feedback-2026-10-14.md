# 2026-10-14 実機確認: 管理情報・特性説明・周期負荷の修正仕様

## /wwc info
- /www info のセクション順を使用する: 基本、血統、行動、能力、性格・特性、成長・老化、怪我。固有情報（スタミナなど）は残す。
- 見出しは各セクションの先頭データ行にのみ接頭辞として表示し、独立行にはしない。
- 能力は `基礎値 (実効値) / ランク名 (正規化値)`、正規化値は小数3桁。canonical の値を換算せず、単位の接尾辞は付けない。
- 強い特性でも実際に強化されるときだけ名前に `II` を付ける（WWWと同基準）。`強`、`弱` は使用しない。
- 親の遺伝情報は `<名前>(<世代>) <血統ID (=Marker)> <性格> <特性>/<特性>`。古いSnapshotに無い項目は推定しない。
- 年齢はWWW同様、基本情報に現在日齢、成長・老化に成長段階と閾値等を表示する。
- コマンド・GUIの文字列は既存WWCのlocale毎の翻訳機構を使う。
- WWC固有項目は削除しない。

## 特性説明
- 通常GUIの特性Loreとクリック後のチャット詳細の双方に、特性名に加えて翻訳済みの説明文を表示する。性格の説明文は復活させない。

## 周期負荷
- 同じtickで全登録個体への能力投影・装備同期・表示再構築を実行しない。
- 未登録復元、legacy Genome移行再試行、外部plugin復元フォールバックの機能は維持する。
- 周期処理を分割して最大同期処理量を抑える。前後のPDC/Attribute/表示状態、world unload、ClickMobs再配置を回帰テストで検証する。
